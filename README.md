# Barotrauma-NT-Carapace
so, this mod is going to add various implants for protecting organs and bones alike
a bit of naming convention: the system of implants as a whole are going to be referred to as "V.O.S.S." which stands for "Vital Organ Safeguard System" (there are going to be a lot of acronyms).
the main implant is the chest implant which comes in two tiers: the S.T.A.R. ("Subdermal Thoracic Armoured Reinforcement") and the C.O.R.E. ("Cardiopulmonary Overlay and Ribcage Exoskeleton"). the S.T.A.R. is an overlapping set of plates (kind of like lamellar armour) which flexes with the ribcage while the C.O.R.E. is a hard, rigid plate that gives very good protection at the cost of making it harder to breathe. both thoracic plates protect the lungs and heart.
there is an optional plate which attatches to a tier two chest implant (C.O.R.E.) to protect the lower torso. this is called the A.E.G.I.S. ("Abdominal Extended Graft Integrated System"). the A.E.G.I.S. is similar to a S.T.A.R. but for the lower torso (abdomen). protects the kidneys and liver from damage
then, there are also may be implants for the extremeties, but this is not decided
